So volgende sprint dink ek ons focus moet wees die Config Audit tool (veral Marthinus Raath) en die Salesforce goed (veral Cornel Coetzee). Soos ons nou die dag bespreek het, doen ons die volgende:

1. Data word gelaai en geskryf (so ver moontlik) deur die API.
2. UI en analises doen ons met geheime agente en gaan ons bos om dit so vining moontlik, maar visueel mooi, te represent. As ons grafieke kan doen, doen dit, maps doen dit. Sodra as ons data update, API endpoints.
3. Dit is belangrik dat ons seker maak ons kode is goed gecomment (vir die nageslag ![🙂](https://statics.teams.cdn.office.net/evergreen-assets/personal-expressions/v2/assets/emoticons/smile/default/30_f.png?v=v83)). AI kan dit doen.
4. Probeer om selfs die API se kode vir Agents te gee, wat dit gaan ons 'n edge gee vorentoe in hierdie veld. Dit beteken die JIRA item moet reg gespec wees en die agent moet access hê na die kode. Dit moet ook kan commit, PR create. ONS approve PRs, nie AI nie (at least vir nou).

Hoop dit maak sin. Ek dink ons moet 'n weeklikse sessie hê soos vanoggend dat ons mekaar kan help en dinge rondom die tech kan besluit. Maar as iets dringend is, moenie wag tot dan nie, vra - want dit is vry.
