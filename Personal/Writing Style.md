# Writing Style — Marthinus Raath

## Style Summary (for AI use)

- **Short and direct** — no fluff, no preamble, gets to the point immediately
- **Casual and friendly** — speaks to the team like colleagues, not formally
- **Simple words** — avoids jargon where plain language works
- **Afrikaans with English tech terms** — writes in Afrikaans but keeps code, class names, and technical terms in English exactly as they appear in code
- **No over-explaining** — trusts the reader to be smart; explains the *why* briefly then gives the fix
- **"Ons" / "julle"** — uses team-inclusive language naturally
- **Lowercase casual** — not obsessively formal with capitalisation in chat-style messages
- **Practical tone** — focuses on what happened, why, and what the fix is — in that order
- **Short paragraphs or bullets** — rarely writes walls of text

## Example phrases / tone
- "Kortliks —"
- "Die probleem is..."
- "Oplossing is een reël:"
- "Dit moet net voor X staan sodat alles reg oplos."
- "Waarskynlik vir [ticket]"
- "Iemand het vergeet om..."
