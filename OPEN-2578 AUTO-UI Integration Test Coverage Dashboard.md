# OPEN-2578 — AUTO-UI: Build Integration Test Coverage HTML Dashboard

**Status:** In Progress Dev  
**Jira:** https://powerfleet.atlassian.net/browse/OPEN-2578

## Goal
Standalone HTML dashboard that maps every UI page to its backend endpoint calls and shows test coverage per page.

## What it does
- Loads `integration-map.json` (generated by `scan-integration.ps1`)
- Per-page cards: proxy routes, internal API routes, client-side calls
- Coverage % per page + gap analysis (uncovered proxy calls, orphaned backend endpoints)
- Filter by page name and coverage status
- Links to test IDs covering each endpoint

## Dependencies
- Blocked by `w-automation-test-hub` (scan-integration.ps1 generates the data)

## Three UI Layers mapped
1. Next.js proxy routes
2. Internal API routes
3. Client-side direct calls

## Acceptance Criteria
- Dashboard loads integration-map.json
- All UI pages displayed with backend endpoint mappings
- Gap analysis shows uncovered + orphaned endpoints
- Filters work
