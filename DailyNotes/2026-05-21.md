### Config Delta permission fix — US ✅ / UAT pending

**Root cause:** `configdiff` schema and all objects were created by `aursqladmin` (migration task). API connects as `appuser`. PostgreSQL does not auto-grant schema access to the database owner — only ZA/ENT/UK/AU/UAE worked because they were tested earlier; US and UAT both surfaced `permission denied for schema configdiff` on first real use.

**Fix applied (US):**
- Reset `aursqladmin` password via `aws rds modify-db-cluster --apply-immediately` (safe — we own this cluster)
- Ran Fargate fix task (`us-pg-migration:11`) → `GRANT USAGE ON SCHEMA configdiff TO appuser; GRANT ALL PRIVILEGES ON ALL TABLES/SEQUENCES`
- Verified: `schema_usage=t`, `tbl_insert=t` ✅
- Skill updated: `ALTER DEFAULT PRIVILEGES` added to Phase 1g setup, Phase 2e (grant fix) added, hard rule added re: never resetting passwords we didn't create
