**Lessons learned (added to both skill files):**
1. **`--database-name` on `create-db-cluster` doesn't always create the DB** — must run explicit `CREATE DATABASE` via Fargate after cluster creation
2. **`\c` metacommand fails in base64-pipe mode** — split into two separate Fargate tasks: (A) create user + DB + DB-level grants vs `postgres`, (B) schema + schema grants vs `operations_tools`
3. **Engine version check required** — `15.4` doesn't exist in `af-south-1`; always run `describe-db-engine-versions` first
4. **Execution role is account-specific** — never hardcode `ecsTaskExecutionRole`; always resolve from existing API task def
