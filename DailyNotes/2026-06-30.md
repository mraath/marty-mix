# 2026-06-30

## OPEN-2936 — Linux Agent Path Fixes

Continued from Session 7. Identified and fixed the two remaining PA test pipeline failures.

### Bugs Fixed

**Bug B — run-test.ps1 wrong environments.json path**
- Was loading `$hubRoot\environments.json` (hub root, backslash) → "Cannot find path" on Linux
- Fixed to `Join-Path $hubRoot "systems/automation/environments.json"` + `Resolve-Path` for all relative traversal
- Also: now passes `-HubRoot $hubRoot` to `run-tests.ps1` so it doesn't fall back to hardcoded Windows default

**Bug C — run-tests.ps1 Windows-only paths**
- Default `$HubRoot = "C:\Projects\Skills\w-automation-test-hub"` → crashes immediately on Linux
- Fixed: default empty → `Resolve-Path "$PSScriptRoot/../../w-automation-test-hub"` after param block
- All `Set-Content -Encoding UTF8` removed (unsupported on some Linux pwsh builds)
- All `$HubRoot\data` etc. backslash strings → `Join-Path $HubRoot "data"`

### Pattern Learned — PowerShell on Linux ADO Agents
See [[feedback_powershell_linux_paths]]:
- `Resolve-Path "$PSScriptRoot/../../folder"` not `"$PSScriptRoot\..\..\folder"`
- `Join-Path $root "sub/path"` not `"$root\sub\path"`
- No `-Encoding UTF8` on `Set-Content` (default UTF8 on pwsh 6+ anyway)
- Never hardcode `C:\...` as a param default
