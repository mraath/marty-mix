## ZAGOV Automation Deployment ✅ (mostly)

Set up the full Powerfleet Automation stack in the ZA Government AWS account (`120736098406`, `af-south-1`).

**Key learning:** ZAGOV uses **AWS IAM Identity Center**, not Okta SAML. `aws sso login --profile zagov` — profile added to `~/.aws/config`.

**What was done:**
- ECS cluster, ALB, SGs, ECR repos, target groups, ALB rules, task defs, ECS services
- ADO pipeline stages added to both API + UI repos (`ForceDeployZAGOV` parameter, manual-only)
- ADO `ZAGOV` environment (id: 467) + service connection `srvcdeploy-zagov-OperationsTools` created
- All AWS skills updated with ZAGOV details + IAM Identity Center pattern

**Bug found & fixed post-deploy:** API entered a crash loop — `appsettings.zagov.json` (lowercase) was silently ignored in the Linux container because the loader generates `appsettings.ZAGOV.json` (uppercase). All other envs are already uppercase (ZA, AU, etc.) — ZAGOV was the exception. Renamed to `appsettings.ZAGOV.json`, committed `875445b` on `feature/OPEN-ZAGOV-pipeline-stage`.
