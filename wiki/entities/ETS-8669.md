ETS-8669 was an incident in March 2026 where [[Command-45]] was not being sent to FM units in the [[OMAN-Environment]] (v18.17). Mix4000 units worked; FM units did not.

## Key Facts

- **Jira:** https://powerfleet.atlassian.net/browse/ETS-8669
- **Environment:** OMAN (v18.17, unsupported)
- **Reported by:** Riaan Serfontein
- **DB affected:** `Schlumberger-OPG-Oman`, OrgID `700083822000352569`
- **Resolution date:** 2026-03-06

## Root Cause

The FMTimeAdjuster tool was being run **from the jumpbox**. Due to network/firewall restrictions in OMAN, the jumpbox cannot correctly route authentication requests to the IIS APIs. Every login attempt succeeded in writing a session to Redis via DynaMiX.Api, but FMTimeAdjuster.Api read from a different network path — resulting in 100% `UnauthenticatedException`.

**Resolution:** Run the tool directly on **HSOMNIIS19**. Use the **older** of the two tool versions found at `C:\Projects\`.

## What Was Eliminated

- Redis config mismatch — all four `web.config` files were verified identical (RedisServerUrl=10.25.2.23, RedisDatabaseIndex=2)
- Missing logical devices on FM assets — not needed to investigate once tool ran correctly
