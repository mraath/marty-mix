# ConfigTools URLs

| Env | UI URL | API URL |
|-----|--------|---------|
| INT | [https://configtools.mixdevelopment.com](https://configtools.mixdevelopment.com) | [https://configtools-api.mixdevelopment.com/swagger](https://configtools-api.mixdevelopment.com/swagger) |

> **INT** is on the `mixdevelopment.com` domain, not `mixtelematics.com`.
> All others will follow `configtools.{env}.mixtelematics.com` / `configtools-api.{env}.mixtelematics.com`.
> **AU** will break the dot pattern — use `configtools-au.mixtelematics.com` (hyphen) to stay within one subdomain level of the wildcard cert.
