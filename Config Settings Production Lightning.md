==Zeshan==

Hi Team! Just a quick note, when you make changes to the following file: appsettings.INT.json - Repos
or any similar settings file on the Config Api, you need to post those settings manually over to the Lightning Configurations Api for these to take affect. 
The URLs for the Lightning Configurations Api can be found here: appsettings.json - Repos
Once the settings are updated, we need to launch new ECS tasks for the new settings to be used.
 
If you have not done theses settings updates before or you need help updating the settings, please feel free to reach out.
